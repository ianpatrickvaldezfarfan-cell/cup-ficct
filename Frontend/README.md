FRONTEND - CUP-FICCT
Framework: React 18
Estilos: Bootstrap 5 + CSS inline
Bundler: Vite

Componentes principales:
- LandingPage: pagina publica de bienvenida
- Login: autenticacion de usuarios
- Registro: flujo de 4 pasos para postulantes
- SubirDocumentos: subida de 4 documentos
- PasarelaPago: simulacion de pago Bs. 700
- RegistroExito: credenciales generadas
- Dashboard: panel administrativo principal
- Postulantes: CRUD postulantes
- Postulaciones: gestion de postulaciones
- Examenes: registro y consulta de notas
- Grupos: asignacion automatica de grupos
- Docentes: gestion de docentes
- Usuarios: gestion de usuarios y roles
- Bitacora: historial de auditoria

Paleta de colores:
- Azul primario: #1a3a6b
- Azul secundario: #2563eb
- Dorado: #f59e0b
- Blanco: #ffffff
